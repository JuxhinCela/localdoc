# Contributing

LocalDoc exists to make personal document tools portable. Contributions should
protect that mission: user-owned documents, local-first workflows, and no
vendor lock-in.

## Development

```bash
npm install
npm run check
```

## Guidelines

- Keep the format small and understandable.
- Preserve unknown metadata when reading and writing projects.
- Prefer portable behavior over editor-specific assumptions.
- Do not add branding, UI, or compatibility claims that imply affiliation with
  any office suite vendor.
- Use synthetic fixtures only. Do not commit private documents.
