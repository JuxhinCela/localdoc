# Roadmap

## v0.2.0-alpha.0

- Position LocalDoc as protocol infrastructure, not an editor framework.
- Add v0.2 spec docs and ADRs.
- Add JSON Schema validation.
- Add valid/invalid fixture suites.
- Add `localdoc conformance`.
- Add conversion-loss reporting.
- Add extension fallback rules.

## v0.2 Alpha Next

- Activate GitHub Actions under `.github/workflows/ci.yml`.
- Publish `localdoc@alpha` to npm.
- Add a Tiptap/ProseMirror adapter with support matrix and loss reports.
- Add browser interchange demo.
- Add asset existence and MIME checks.
- Add issue templates and conformance badge docs.

## Later

- Optional DOCX and ODT import/export adapters.
- Lexical and Slate adapters.
- Visual document diff tools.
- Collaboration snapshot import/export guidance.
