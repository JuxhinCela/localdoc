# Roadmap

## v0.1

- LocalDoc folder project format.
- TypeScript SDK.
- CLI for init, inspect, validate, and convert.
- Markdown and HTML import/export.
- Two tiny compatibility demos.

## v0.2

- Richer tables and nested lists.
- Asset manifest checks.
- Browser demo editor.
- More AI-builder templates.

## Later

- Optional DOCX import/export adapter.
- Plugin contract for custom blocks.
- Conformance test suite for third-party editors.
- Visual document diff tools.
