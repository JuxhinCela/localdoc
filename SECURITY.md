# Security Policy

LocalDoc is a file format, SDK, and CLI for local document projects.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a Vulnerability

Please open a private security advisory on GitHub if the issue could expose
private document data, corrupt documents, or create unsafe CLI behavior.

Do not include private documents, secrets, or sensitive personal data in public
issues. Use small synthetic examples whenever possible.
