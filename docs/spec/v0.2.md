# LocalDoc v0.2 Spec

LocalDoc v0.2 defines a local-first package format for portable rich-text
documents.

Normative terms such as MUST, SHOULD, and MAY are used in the RFC 2119 sense.

## Package Layout

A LocalDoc package MUST be a directory ending in `.localdoc` with:

```text
document.localdoc/
  manifest.json
  document.json
  assets/
```

Processors MUST reject packages with unsupported major versions by default.

## Core Principle

LocalDoc stores document interchange state, not editor runtime state.

Core documents MUST NOT require cursor state, selection state, undo stacks,
plugin state, or collaboration engine internals.

## Profiles

v0.2 defines one implemented profile:

- `core-richtext`: paragraphs, headings, quotes, code blocks, lists, links,
  images, tables, inline marks, metadata, and custom blocks with fallbacks.

Future profiles MAY cover richer assets, layout metadata, and adapter-specific
conformance.
