# Governance

LocalDoc is currently maintained by its primary maintainer.

## Decision Process

- Format changes require an issue or PR that explains compatibility impact.
- Schema changes require valid and invalid fixture updates.
- Adapter claims require tests and loss-reporting notes.
- Security-sensitive parsing changes require focused tests.

## Maintainer Responsibilities

- Review issues and pull requests.
- Maintain releases, schemas, fixtures, and conformance checks.
- Keep public copy honest about project scope and compatibility.
